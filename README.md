# Домашний тренер

Android-приложение для домашних тренировок без инвентаря.

Внутри:
- 7-дневный план;
- упражнения по подходам и повторениям;
- режим «5 минут», чтобы не выпадать из привычки;
- таймер отдыха;
- история и серия тренировок;
- прогресс по группам мышц;
- постепенное повышение нагрузки.

APK собирается автоматически через GitHub Actions.

## Где скачать APK

Откройте вкладку **Actions** → последний запуск **Build APK** → внизу страницы скачайте артефакт **DomashniyTrener-APK**.

Исходный Android-проект хранится в архиве `project.zip.b64` (Base64). Workflow автоматически декодирует его перед сборкой.
